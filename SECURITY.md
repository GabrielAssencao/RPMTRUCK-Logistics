# Política de segurança

## Versões suportadas

Correções de segurança são mantidas na versão presente na branch `main`.

## Como reportar uma vulnerabilidade

Não abra uma issue pública com detalhes exploráveis, credenciais ou dados reais.
Use **Security > Advisories > Report a vulnerability** no GitHub para enviar um
relato privado. Inclua impacto, pré-condições, passos mínimos de reprodução e uma
sugestão de correção, quando possível.

O recebimento será confirmado assim que o mantenedor revisar o relato. A
divulgação deve ser coordenada e ocorrer somente depois de existir uma correção
ou mitigação adequada.

## Escopo

Relatos de autorização multiempresa, autenticação, recuperação de senha,
exposição de dados, uploads, Storage, RLS, funções privilegiadas e vazamento de
segredos têm prioridade. Não realize testes destrutivos, indisponibilidade,
engenharia social ou acesso a dados de terceiros.
